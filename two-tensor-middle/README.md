# Run the middle transform on integer tensor cores

Reuse the exact radix-16 transform from the earlier tensor-middle experiment on the measured two-digit graph. For each 256-coefficient row, two matrix passes transform A, two transform B, and two recover the cyclic product. Each pass uses sixteen INT8 warp matrix instructions. The rest of the three-stream graph, including its input conversion, outer transforms and CRT, comes from the 45.603 ms control.

The earlier tensor kernel used a 64-bit high multiply to reduce each byte-dot result. Here the largest 64-byte dot represents a value below `64 × 255 × p < 2^45` for these primes. The existing 48-bit reciprocal reducer uses a 32-bit high multiply and one final correction over that range. The fixed 16-point weights are shared between the signed channels. After the final inverse reads its permuted result, the warp reuses that shared tile for the coalesced output transpose. Total static shared storage falls from 23,680 to 15,488 bytes versus the original tensor kernel.

The ranked batch executes 364,904,448 warp matrix instructions for the middle stage, plus row rotations, byte-dot reductions and shared-memory operations. That shifts work from the scalar butterflies to the integer tensor path. The exact host test checks all packed weights and each dot evaluated in the six cyclic products. It also compares the weighted inverse output after the in-place transpose and verifies that every output warp uses each shared bank once.
